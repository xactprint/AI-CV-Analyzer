# Screenshots

Drop the README image captures here using these file names — the root README links to them
directly:

| File                | What it shows                                  |
| ------------------- | ---------------------------------------------- |
| `landing.png`       | Animated landing page with hero and features    |
| `dashboard.png`     | Dashboard: stat cards, charts, recent analyses  |
| `analysis.png`      | Analysis results: score, skills, experience     |
| `job-matcher.png`   | Job matcher: match score and missing skills     |

Suggested capture size: 1440 × 900, light and dark variants as `*-dark.png`.
